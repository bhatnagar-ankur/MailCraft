# @bhatnagar-ankur/mailcraft-types

> Shared TypeScript type contracts for MailCraft

[![npm](https://img.shields.io/npm/v/@bhatnagar-ankur/mailcraft-types)](https://www.npmjs.com/package/@bhatnagar-ankur/mailcraft-types)
[![License: MIT](https://img.shields.io/badge/License-MIT-blue.svg)](https://github.com/bhatnagar-ankur/MailCraft/blob/master/LICENSE)

This package contains the shared TypeScript interfaces used by `@bhatnagar-ankur/mailcraft-core`. Install it if you need to type-annotate MailCraft objects in your own code.

---

## Installation

```bash
npm install @bhatnagar-ankur/mailcraft-types
```

---

## Types

```typescript
import type {
  RenderOptions,
  RenderResult,
  RenderedEmail,
  IEmailAdapter,
  AdapterConfig,
  SendResult,
  ValidationResult,
  TemplateMetadata,
  TemplateSchema,
  TemplateVariable,
  AlertType,
} from '@bhatnagar-ankur/mailcraft-types';
```
